### Usage

```html
%stacksVersionAsInteger%
```


### Description

This is replaced with the version number of Stacks as an integer.

This is not meant to be a human readable version and should *never* be displayed as output to the user anywhere inside Stacks.


> This is the version number of Stacks -- *NOT your* stack. For the version number of your stack [see stack Version](../stackVersion).

> This template is applied in the pre-processor and has very low performance cost.
